1. Objetivo PrincipalExplorar e validar estatisticamente a relação entre os dados de detenções policiais no Arizona e a prevalência de indicadores de Ansiedade e Depressão na região.
2. MetodologiaO projeto aplicou as três áreas da Estatística em rotinas de código Python, utilizando as bases de dados de detenções (POLTRA_25.csv) e indicadores de saúde (indica.csv).
3. Descritiva: Gráficos de tendências temporais, Boxplots por gênero, Tabela de Contingência/Qui-Quadrado.
4. Probabilidade: Cálculo da Probabilidade Condicional Probabilidade de Mulher Detida, dado que o Indicador está Alto.
5. Inferência: Teste t de Hipótese para comparar a diferença de médias dos indicadores entre anos (ex: 2023 vs. 2022).
6. Conclusão: O projeto demonstra a capacidade de integrar bases de dados heterogêneas e utilizar ferramentas estatísticas (AED e Inferência) para testar hipóteses e quantificar riscos condicionais, fornecendo uma análise estruturada e modularizada do fenômeno social e de saúde pública.
