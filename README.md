# An-lise-Estat-stica-de-Dados-de-Deten-es-Policiais-no-Arizona-vs.-Indicadores-de-Sa-de-Mental-
Projeto de Estatística Aplicada explorando a associação entre segurança pública e saúde mental no Arizona. Foco em AED, visualização de dados, cálculo de probabilidades condicionais e inferência estatística (testes de hipótese) usando Python, Pandas e SciPy.
